# 실행 환경 설정 (Windows · Python 3.12 · VSCode)

이 저장소는 **프로젝트 폴더 안의 가상환경 `.venv`(Python 3.12)** 로 실행합니다. 가상환경은 저장소에 올리지 않고(`.gitignore`), PC마다 `requirements.txt`로 새로 만듭니다.

## 1. 처음 한 번 (새 노트북 기준)

### 1-1. 준비물
1. **Python 3.12** — python.org의 Windows installer(64-bit). 설치 화면에서 **"py launcher"** 가 체크되어 있는지 확인합니다. ("Add python.exe to PATH"는 체크하지 않아도 됩니다. 아래에서 버전을 직접 지정합니다.)
2. **VSCode** + 확장 **Python**(Microsoft), **Jupyter**(Microsoft)
3. **Git** (저장소 내려받기용)

### 1-2. 저장소 내려받기 → 가상환경 만들기
PowerShell에서:

```powershell
cd ~\Desktop
git clone https://github.com/jongha-rdy34/AI_level3_final_ver.git
cd AI_level3_final_ver
py -3.12 -m venv .venv                              # ← 3.12로 '지정'해서 만든다 (py만 쓰면 가장 최신 버전이 잡힘)
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python --version                      # Python 3.12.x 확인
```

- NVIDIA GPU 노트북이면 `requirements.txt` 맨 위 주석의 CUDA판 torch 명령을 추가로 실행합니다(선택). CPU만으로도 전부 실행됩니다.
- `activate`를 하지 않아도 됩니다. `.venv\Scripts\python`처럼 **가상환경의 python을 직접 부르면** 버전이 섞이지 않습니다.

### 1-3. VSCode에서 열기
1. VSCode → **파일 → 폴더 열기** → `AI_level3_final_ver` 폴더 (파일 하나가 아니라 **폴더**를 엽니다)
2. 저장소에 들어 있는 `.vscode/settings.json`이 인터프리터를 `.venv\Scripts\python.exe`로 고정합니다.
3. 확인: `Ctrl+Shift+P` → **Python: Select Interpreter** → `Python 3.12.x ('.venv': venv) .\.venv\Scripts\python.exe`가 선택되어 있으면 됩니다.
4. 노트북을 열고 오른쪽 위 **커널 선택(Select Kernel)** → **Python Environments** → **`.venv (Python 3.12.x)`**
   - 노트북마다 한 번 고르면 VSCode가 기억합니다(문제 A, 문제 B, 정답 노트북 각각).
5. 첫 셀을 실행해 `torch 2.5.1` 과 `torchvision.transforms.v2 사용`이 출력되는지 확인합니다.
   - 확인용 셀(아무 셀에나 잠깐): `import sys; print(sys.version, sys.executable)` → 경로에 `.venv`가 있어야 합니다.

## 2. 파이썬 버전이 자꾸 바뀌는 이유와 고정 방법

이 PC에서 확인한 상태: Python **3.14(py 기본값), 3.12, 3.11, 3.9** 와 Microsoft Store용 `python.exe`(바로가기)가 함께 설치되어 있습니다. 그래서
- 터미널에서 `python`·`py`가 무엇을 부르는지가 PATH 순서·py 기본값에 따라 달라지고,
- VSCode가 폴더·노트북마다 다른 인터프리터나 커널을 자동으로 골라 버립니다.

| 원인 | 고정 방법 |
|---|---|
| `py` 기본값이 최신(3.14) | 항상 `py -3.12 ...`로 지정. 또는 `%LOCALAPPDATA%\py.ini` 파일에 아래 두 줄을 넣으면 `py`의 기본값이 3.12가 됩니다 |
| PATH에 python이 여러 개 | 가상환경의 python을 **경로로** 부르기(`.venv\Scripts\python`) |
| Microsoft Store 바로가기 | Windows 설정 → 앱 → 고급 앱 설정 → **앱 실행 별칭**에서 `python.exe`, `python3.exe`(앱 설치 관리자)를 끄기 |
| VSCode가 인터프리터를 바꿈 | 이 저장소의 `.vscode/settings.json`(`python.defaultInterpreterPath`) + **폴더로 열기** |
| 노트북 커널이 바뀜 | 노트북마다 커널을 `.venv`로 한 번 선택. 다른 노트북에서 복사한 셀이 아니라 커널 표시(오른쪽 위)를 확인 |

`py.ini` 예 (`C:\Users\<사용자>\AppData\Local\py.ini`):
```ini
[defaults]
python=3.12
```

## 3. 자주 생기는 문제
- **커널 목록에 `.venv`가 없음** → VSCode 창을 다시 불러오기(`Ctrl+Shift+P` → Developer: Reload Window). 그래도 없으면 `.venv\Scripts\python -m pip install ipykernel` 확인
- **`ModuleNotFoundError: No module named 'torch'`** → 커널이 `.venv`가 아님(오른쪽 위 커널 표시 확인)
- **PowerShell에서 `Activate.ps1` 실행이 막힘** → 활성화하지 말고 `.venv\Scripts\python`을 직접 쓰면 됩니다. (실행 정책을 바꾸는 방법도 있지만 보안 설정이므로 필요할 때 직접 판단하세요)
- **`python -I`로 채점기를 돌렸더니 torch가 없음** → 채점기는 torch가 없어도 됩니다. 노트북 마지막 셀은 커널(= `.venv`)의 python으로 채점기를 실행합니다.
- **가상환경을 처음부터 다시** → VSCode를 닫고 `.venv` 폴더를 지운 뒤 1-2를 다시 실행

## 4. 사양이 낮은 노트북에서
- 이 세트는 **GPU 없이 CPU만으로** 돌아가도록 만들었습니다(모델 입력 64, 약 0.3M 파라미터). 실습 PC(8스레드)에서 정답 노트북 전체가 약 5~6분이었으므로, 오래된 노트북에서는 **2~4배(15~25분)** 걸릴 수 있습니다.
- 가장 오래 걸리는 셀은 Q3 3-6(후보 2~3개 × 12 epoch)과 Q4 4-3(추가 모델 2개)입니다. 먼저 `epochs`를 6 정도로 줄여 끝까지 흐름을 본 뒤, 시간이 될 때 늘리세요(점수는 조금 낮아질 수 있음).
- 공통 준비 셀의 `ps.seed_everything()`이 `torch.set_num_threads(8)`을 부릅니다. 코어가 4개인 노트북이면 그대로 두어도 되지만, 화면이 버벅이면 첫 셀 뒤에 `torch.set_num_threads(4)`를 한 줄 실행하세요.
- 실행 중에는 다른 무거운 프로그램(브라우저 탭 다수 등)을 닫고, 노트북을 전원에 연결해 '최고 성능' 전원 모드로 두면 빨라집니다.
- 디스크: `.venv`가 약 1.9GB입니다.

## 5. 설치되는 것 (`requirements.txt`)
| 용도 | 패키지 |
|---|---|
| 데이터·이미지·지표 | numpy, pandas, pillow, scikit-learn, matplotlib, jsonschema |
| 딥러닝 | torch 2.5.1, torchvision 0.20.1, timm 1.0.11 (timm은 시험 API 연습용, 노트북 모델은 저장소의 `mini_tinyvit.py`) |
| Jupyter | ipykernel(VSCode 커널), jupyterlab(VSCode 밖에서 열 때), ipywidgets, tqdm |
| 노트북 생성·일괄 실행 | nbformat, nbconvert |

torchvision이 설치되면 노트북은 연습용 대체(`tv_compat`) 대신 **진짜 `torchvision.transforms.v2`** 를 씁니다. 지정 모델은 그대로 연습용 축소판(`mini_tinyvit`)입니다.
