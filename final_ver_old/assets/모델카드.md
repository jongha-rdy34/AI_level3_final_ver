# 모델 카드: TinyViT-5M (지정 모델) / 연습용 축소판

| 항목 | 실제 TinyViT-5M (시험, 예상) | 이 세트의 연습용 축소판 |
|---|---|---|
| 불러오기 | `timm.create_model("tiny_vit_5m_224", pretrained=True, ...)` (가중치는 로컬에 설치) | `mini_tinyvit.create_model("tiny_vit_5m_224", pretrained=True)` |
| 파라미터 | 약 5.4M | 약 0.2M |
| 입력 크기 | **(3, 224, 224)** | (3, 64, 64) |
| 정규화 | ImageNet **mean (0.485, 0.456, 0.406), std (0.229, 0.224, 0.225)** | 같음 |
| 보간·crop_pct | bicubic, 0.95 | 같은 값을 `pretrained_cfg`에 둠 |
| 사전학습 | ImageNet-22k 증류 → ImageNet-1k (1,000클래스) | 합성 도형 16종 6,720장 (확인 정확도 0.97) |
| 구조 | `patch_embed` → `stages[0]`(MBConv, 합성곱) → `stages[1..3]`(PatchMerging + attention 블록) → `head` | 같은 이름, 깊이·폭만 축소 |
| head | `head.global_pool → head.norm(LayerNorm) → head.fc(Linear(320, 1000))` | `head.fc = Linear(96, 16)` |
| 정규화 층 | 합성곱 단계 BatchNorm, attention 단계 LayerNorm | 같음 |

## 사용 시 주의
- **전처리 값은 모델에서 읽습니다:** `resolve_data_config(model=model)` → `input_size`, `mean`, `std`, `interpolation`, `crop_pct`. 숫자를 직접 쓰지 않으면 실제 모델로 바꿔도 코드가 그대로 동작합니다.
- **출력층 교체:** `model.reset_classifier(20)` 또는 `model.head.fc = nn.Linear(model.head.fc.in_features, 20)`. 생성할 때 `num_classes=20`을 주어도 timm이 head를 새로 만듭니다.
- **학습 범위 이름:** `head`, `stages.3`, `stages.2`, `stages.1`, `stages.0`, `patch_embed`
- 입력 크기를 224가 아닌 값으로 바꾸면 attention 단계의 창 크기·위치 bias 때문에 timm에서 오류가 나거나 성능이 떨어질 수 있습니다. 사전학습 크기(224)를 지키세요.
- `drop_path_rate`(stochastic depth)는 생성할 때 인자로 줍니다: `create_model(..., drop_path_rate=0.1)`.

출처: 연습용 가중치(`tiny_vit_practice.pt`)는 Claude가 합성 도형으로 CPU에서 학습했습니다(`정답_채점용/_build/make_data_v3.py`의 `pretrain()`). 실제 TinyViT 가중치가 아닙니다. 실제 TinyViT-5M의 수치는 일반적으로 알려진 값이며, 시험 환경의 버전·경로는 문제의 안내를 따르세요.
