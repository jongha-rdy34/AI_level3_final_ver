# 지정 모델과 제공 함수 (이 모의 전용)

## 지정 모델 — `mini_tinyvit` (timm과 같은 이름)
- `create_model("tiny_vit_5m_224", pretrained=True, num_classes=None, drop_path_rate=0.0, drop_rate=0.0, checkpoint_path=None)` → `TinyVit`
- `resolve_data_config(model=model)` → `{"input_size": (3, 64, 64), "interpolation": "bicubic", "mean": (...), "std": (...), "crop_pct": 0.95}`
- `model.pretrained_cfg`, `model.reset_classifier(n)`, `model.get_classifier()`, `model.num_features`, `model.forward_features(x)`, `model.forward_head(x, pre_logits=False)`
- 하위 모듈: `patch_embed`, `stages[0..3]`, `head(global_pool, norm, fc)` — 자세한 내용은 `assets/모델카드.md`, `timm_tinyvit.md`

## `practice_support` (노트북에서 `ps.`)
### 데이터
- `ps.DATA`, `ps.SUBMIT`, `ps.CLASSES`(20개), `ps.CLASSES_KO`
- `ps.read_table(name)` → `data/name`을 id 문자열로 읽은 DataFrame
- `ps.show_images(images, titles=None, ncols=8)`: PIL 이미지 또는 uint8 배열 리스트 격자
- `ps.preload(files, size, load_fn, pad_fn)` → `(N, size, size, 3)` uint8 (불러오기 → 패딩 → bicubic 크기 조정)
- `ps.zoom_out(images, scale=0.5, fill=255)` → 물체를 줄여 가운데 둔 사진 배열(작게 찍힌 test 사진을 흉내 낸 검증용)
- `ps.file_md5(path)`

### Q5
- `ps.mock_llm(text_id)` → str: **모의 응답**(지정 모델은 이미지 모델이라 채팅 불가). 프롬프트와 무관
- `ps.check_prompt(prompt, text, schema_keys)` → 빠진 요소 리스트(품질 채점 아님)
- `ps.save_jsonl(records, name)`

### 제출·기타
- `ps.check_submission(kind)` → 문제 목록(`[]`이면 통과). `kind`: `"q3"`, `"q4"`, `"q5"` — `제출가이드.md` 규칙
- `ps.attempt(name, fn, *args)`, `ps.seed_everything(seed)`, `with ps.Timer("이름"):`
- 진행용 대체물(앞 소문항 실패 시 확인 셀이 자동 사용): `ps.ready_normalize_label`, `ps.ready_load_rgb`, `ps.ready_pad_to_square`, `ps.ready_clean_table()`, `ps.ready_transforms(train, cfg)`, `ps.ReadyProductDataset`, `ps.ready_train_loader`
