# Reference 목차

FAQ에 따르면 시험에서는 **라이브러리 공식 문서가 레퍼런스로 제공**됩니다. 이 폴더는 그 상황을 연습하려고 공식 문서 형식(시그니처 → 매개변수 → 반환 → 주의 → 예시)으로 **자주 쓰는 부분만** 다시 정리한 것입니다. 공식 문서를 옮긴 것이 아니며, 버전에 따라 세부가 다를 수 있습니다.

**연습 방법:** 먼저 "어떤 API가 필요한가"를 정한 뒤 해당 페이지에서 시그니처를 확인하세요. 실제 공식 문서는 분량이 훨씬 많아서, 검색어(클래스·함수 이름)를 알고 있는지가 시간을 크게 좌우합니다.
